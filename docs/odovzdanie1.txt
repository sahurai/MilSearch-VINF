===== 1. Opis projektu a cieľ =====

**MilSearch** je vyhľadávač vojenskej techniky. Pokrýva tri oblasti: ručné zbrane (pušky, pištole, guľomety), obrnenú techniku a delostrelectvo (tanky, obrnené vozidlá, húfnice) a vojnové lode a ponorky.

**Motivácia.** Bežný fulltext nevie odpovedať na otázky ako „hlavné bojové tanky rýchlejšie ako 70 km/h“ alebo „nemecké ponorky z rokov 1939–1945“. Na to treba štruktúrované údaje: krajinu, rok, kaliber, rýchlosť, výtlak. MilSearch tieto údaje vyextrahuje z HTML a spojí fulltextový ranking s filtrami nad poľami.

**Cieľ 1. časti:** vlastný crawler, extrakcia entít a parametrov regulárnymi výrazmi, vlastný invertovaný index, ranking a porovnanie metód idf. \\
**Cieľ 2. časti:** spojenie s Wikipédiou (EN, SK) v Apache Spark a index v PyLucene.

===== 5. Architektúra crawlera =====

{{milsearch_crawler_architecture.png?direct&1100|Architektúra crawl systému MilSearch}}

  - **Frontier** vráti ďalšiu URL. Každá kategória má vlastnú FIFO frontu (BFS). Fronty sa striedajú (round-robin).
  - **Fetcher** skontroluje robots.txt, počká minimálne 2 s + 0–1 s a pošle GET (retry pri 429/5xx/timeoute).
  - **Deduplikácia:** výsledná URL po redirecte a SHA-1 hash obsahu.
  - **Úložisko:** HTML do ''data/raw/<kategória>/<id>.html'', záznam do ''fetched.jsonl''.
  - **Odkazy:** regex nájde ''<a href>''. Crawler URL normalizuje a vyfiltruje. Nové URL zapíše do ''discovered.jsonl'', anchor texty do ''anchors.tsv''.
  - **Obmedzenia:** iba ''www.militaryfactory.com'', iba 3 typy URL (regex), MIME ''text/html'', max. 8 MB, hĺbka 3, URL max. 300 znakov.
  - **Prerušenie:** stav je v append-only súboroch. Po ''Ctrl+C'' crawler pokračuje tam, kde skončil. Nič sa nemaže.

<code python>
def build_canonical_url(href: str, base_url: str) -> str | None:
    """
    Make a canonical absolute URL from a link.

    Steps:
        1. Resolve the link against the page URL.
        2. Reject a scheme other than http/https and a different host.
        3. Change the path suffix .asp to .php and remove the fragment.

    Returns:
        Canonical URL; None when the link goes out of the site.
    """
    # 1. Resolve the link against the page URL
    parts = urlsplit(urljoin(base_url, html.unescape(href.strip())))

    # 2. Reject a scheme other than http/https and a different host
    if parts.scheme not in ("http", "https"):
        return None
    host = parts.netloc.lower()
    if host == "militaryfactory.com":
        host = ALLOWED_HOST
    if host != ALLOWED_HOST:
        return None

    # 3. Change the path suffix .asp to .php and remove the fragment
    # The server answers detail.asp with HTTP 301 to detail.php.
    path = re.sub(r"\.asp$", ".php", parts.path)
    return urlunsplit(("https", host, path, parts.query, ""))
</code>

<code python>
def extract_links(page_html: str, base_url: str) -> list[Link]:
    """
    Find all links of a page that are in the crawl scope.

    Steps:
        1. Find each <a> element and its href attribute.
        2. Make the canonical URL and keep only URLs in the crawl scope.
        3. Build a Link with the anchor text and the title attribute.

    Returns:
        Links in page order; the list can contain the same URL more than one time.
    """
    links: list[Link] = []

    # 1. Find each <a> element and its href attribute
    for attributes, inner_html in _ANCHOR_RE.findall(page_html):
        href = _HREF_RE.search(attributes)
        if not href:
            continue

        # 2. Make the canonical URL and keep only URLs in the crawl scope
        url = build_canonical_url(href.group(1), base_url)
        scope = get_url_scope(url) if url else None
        if not scope:
            continue

        # 3. Build a Link with the anchor text and the title attribute
        title = _TITLE_RE.search(attributes)
        links.append(Link(
            url=url,
            kind=scope[0],
            category=scope[1],
            anchor_text=_get_plain_text(inner_html)[:_MAX_ANCHOR_TEXT_LENGTH],
            title=html.unescape(title.group(1)) if title else "",
        ))
    return links
</code>

Číslo s jednotkou z textu, napr. ''"42 mph (67 kph)"'' → 67.0 km/h ([[https://github.com/sahurai/MilSearch-VINF/blob/main/extractor/parse.py#L212-L229|riadky 212–229]]):

<code python>
def _get_unit_number(value: str | None, unit_pattern: str | None) -> float | None:
    """
    Get the number in front of a unit, for example "42 mph (67 kph)" and r"kph\\b" -> 67.0.

    Steps:
        1. Without a unit pattern, get the first number.
        2. With a unit pattern, find the number that the unit follows.

    Returns:
        Number; None when the text does not contain the number or the unit.
    """
    # 1. Without a unit pattern, get the first number
    if unit_pattern is None:
        return _get_number(value)

    # 2. With a unit pattern, find the number that the unit follows
    match = re.search(rf"(\d[\d.,]*)\s*(?:{unit_pattern})", value or "")
    return _get_number(match.group(1)) if match else None
</code>

**Kontrola kvality:**
  * Každé číselné pole má prijateľný rozsah. Hodnota mimo rozsahu je chyba na stránke. Extraktor ju zmení na ''None'' a zapíše do ''implausible_fields''.

**Tokenizácia** (rovnaká pre dokumenty aj dopyty):
  * regex ''[a-z0-9]+(?:[.\-/][a-z0-9]+)*'', malé písmená, odstránenie diakritiky,
  * zložené tokeny ostávajú celé a pridajú sa aj ich časti: ''t-80'' → ''t-80'', ''t'', ''80''; ''7.62x39mm'' → aj ''7.62x39'',
  * krátky zoznam stop slov (slová ako //main//, //heavy//, //battle// ostávajú, sú dôležité v doméne),
  * S-stemmer (Harman): odstráni iba množné číslo. Lematizáciu podľa zadania nerobím.

**Zóny a TF.** Tf termu je súčet váh zón, v ktorých sa term nachádza:

^ Zóna ^ Váha ^
| ''name'' | 3 |
| ''type'', ''roles'', ''country'', ''caliber'', anchor texty odkazov z iných detailov | 2 |
| ostatné polia a text článku | 1 |

<code python>
def index_document(document: Document, anchor_texts: list[str]) -> dict[str, tuple[float, list[int]]]:
    """
    Change one document into weighted term frequencies and term positions.

    Steps:
        1. Go through the zones in a fixed order.
        2. Add the zone weight to the tf of each term and keep the term position.
        3. Leave a position gap after each zone.

    Returns:
        Map from term to (weighted tf, positions).
    """
    tf_by_term: dict[str, float] = defaultdict(float)
    positions_by_term: dict[str, list[int]] = defaultdict(list)
    position = 0

    # 1. Go through the zones in a fixed order
    for zone, weight in ZONE_WEIGHTS.items():
        groups = get_term_groups(_get_zone_text(document, zone, anchor_texts))

        # 2. Add the zone weight to the tf of each term and keep the term position
        for group in groups:
            for term in group:
                tf_by_term[term] += weight
                positions_by_term[term].append(position)
            position += 1

        # 3. Leave a position gap after each zone
        position += _ZONE_POSITION_GAP
    return {term: (tf_by_term[term], positions_by_term[term]) for term in tf_by_term}
</code>

===== 11. Metódy výpočtu idf =====

Súbor: [[https://github.com/sahurai/MilSearch-VINF/blob/main/indexer/ranking.py|indexer/ranking.py]]. N = počet dokumentov, df = počet dokumentov s termom.

^ Idf ^ Vzorec ^ Správanie ^
| klasické | ''log10(N / df)'' | Prednáška 06. Term vo všetkých dokumentoch má idf 0. |
| smooth | ''log10(N / (1 + df)) + 1'' | „+ 1“ mimo logaritmu: časté termy majú váhu okolo 1, nie 0. Rozdiely medzi termami sú menšie. |
| BM25 | ''ln((N − df + 0.5) / (df + 0.5) + 1)'' | Prednáška 06 (BM25). „+ 1“ zabráni zápornej hodnote pre termy vo viac ako polovici dokumentov. |

**Pravdepodobnostné idf** ''log((N − df) / df)'' **nepoužívam** – zadanie ho zakazuje.

**Zistenie:** BM25 idf sa dá upraviť na ''ln((N + 1) / (df + 0.5))''. Pre zriedkavé termy je to takmer ''ln 10 × log10(N / df)'', teda klasické idf krát konštanta 2,3. Termy v dopyte preto dostanú rovnaký podiel váhy (tabuľka v kapitole 12). Rozdiel medzi ''tfidf'' a ''bm25'' teda nespôsobuje idf, ale saturácia tf a normalizácia dĺžky v BM25.

**Metódy rankingu:**

^ Metóda ^ Idf ^ Skóre ^
| ''tfidf'' | klasické | kosínusová podobnosť, SMART lnc.ltc: dokument ''(1 + log10 tf) / norma'', dopyt ''(1 + log10 tf) × idf'' |
| ''tfidf_smooth'' | smooth | rovnaká kosínusová podobnosť – líši sa iba idf |
| ''bm25'' | BM25 | Okapi BM25, ''k1 = 1.2'', ''b = 0.75'' |

<code python>
def compute_idf_classic(documents_count: int, df: int) -> float:
    """
    Compute the classic inverse document frequency.

    Steps:
        1. Return log10(N / df); a term without documents has idf 0.

    Returns:
        Classic idf, 0 or more.
    """
    # 1. Return log10(N / df); a term without documents has idf 0
    return math.log10(documents_count / df) if df else 0.0


def compute_idf_smooth(documents_count: int, df: int) -> float:
    """
    Compute the smooth inverse document frequency.

    Steps:
        1. Return log10(N / (1 + df)) + 1; a term without documents has idf 0.

    Returns:
        Smooth idf; approximately 1 for a term in all documents.
    """
    # 1. Return log10(N / (1 + df)) + 1; a term without documents has idf 0
    return math.log10(documents_count / (1 + df)) + 1 if df else 0.0


def compute_idf_bm25(documents_count: int, df: int) -> float:
    """
    Compute the BM25 inverse document frequency (always positive).

    Steps:
        1. Return ln((N - df + 0.5) / (df + 0.5) + 1).

    Returns:
        BM25 idf, more than 0.
    """
    # 1. Return ln((N - df + 0.5) / (df + 0.5) + 1)
    return math.log((documents_count - df + 0.5) / (df + 0.5) + 1)
</code>
